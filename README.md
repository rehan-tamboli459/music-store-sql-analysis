# 🎵 Music Store Data Analysis using SQL

## 📌 Project Overview

This project analyzes a music store database using PostgreSQLto uncover customer purchasing behavior, sales performance, genre popularity, and revenue trends. The analysis answers real-world business questions using SQL queries ranging from basic joins to advanced window functions.

This project is based on a public music store dataset and has been organized as part of my **Data Analyst Portfolio**.

---

## 🎯 Business Objectives

* Identify the senior-most employee.
* Find countries with the highest number of customers.
* Analyze top customers based on total spending.
* Calculate revenue generated by each country.
* Identify the best-selling genres, artists, and tracks.
* Find the top customer for each country using window functions.

---

## 💡 Key Insights

* Customer spending varies significantly across countries.
* A small group of customers contributes a large share of revenue.
* Rock is one of the most purchased genres in multiple countries.
* Window functions help identify top customers even when there are ties.
